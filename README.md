# QQRM Legacy

Законченные и замороженные проекты. Публичные витринные репозитории остаются доступными для просмотра, но больше не развиваются; всё остальное лежит архивом.

Finished and frozen projects. Public showcase repositories stay readable, but no further development is planned; everything else is kept as a read-only archive.

## Showcase — законченные проекты

Публичные проекты, которыми не стыдно поделиться. Статус: complete / frozen.

- **[webgpu-candles](https://github.com/qqrm-legacy/webgpu-candles)** — интерактивный свечной график на WebGPU, Rust и WebAssembly, с живыми данными Binance.
- **[chatgpt-better-experience](https://github.com/qqrm-legacy/chatgpt-better-experience)** — Firefox-расширение с набором улучшений ChatGPT/Codex. Развитие остановлено: интерфейс ChatGPT меняется слишком часто. Последняя версия остаётся на AMO.
- **[another-it-tg-bridge](https://github.com/qqrm-legacy/another-it-tg-bridge)** — бот, который находит свежие статьи Another IT и публикует ссылки в Telegram.
- [aoc2023](https://github.com/qqrm-legacy/aoc2023), [aoc2024](https://github.com/qqrm-legacy/aoc2024), [aoc2025](https://github.com/qqrm-legacy/aoc2025) — решения Advent of Code на Rust.

## Где идёт активная разработка

- [qqrm](https://github.com/qqrm) — поддерживаемые продукты и витрина профиля.
- [qqrm-labs](https://github.com/qqrm-labs) — активные эксперименты, боты, шаблоны и лаборатории.

Everything in this organization is archived: issues and pull requests are closed, and CI is disabled.
